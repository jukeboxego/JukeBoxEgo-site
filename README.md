# Juke Box Ego Website

## About this website

This is the official-style landing page for Juke Box Ego, bringing gaming videos, creator projects, social channels, and contact information together in one responsive website. It uses a dark navy and black interface with electric-blue and neon-cyan accents. The featured project is BOB, a horror-based cartoon parody with an eerie, darkly playful tone. The BOB links on this page lead to the dedicated BOB landing page.

## Website features

- Responsive navigation and sections for About, Projects, Socials, Content, and Contact
- Featured BOB artwork and direct links to the BOB landing page
- Static YouTube Short thumbnail linking to the video
- TikTok preview that loads the embedded player on hover/focus, or tap on touch devices
- Floating social shortcuts for YouTube, TikTok, Discord, BOB, and Linktree
- Contact form that prepares an email addressed to `jukeboxego@gmail.com`
- Keyboard focus styling, responsive layout, and reduced-motion support

## Run locally

Extract the ZIP and run `Run Website Locally.bat` for a local HTTP preview. Keep the `assets` folder beside `index.html`. You can also open `index.html` directly, but some browser embeds may behave differently from a hosted HTTPS page.

The contact form cannot send email directly from static HTML. It opens the visitor's default email application with the message filled in; the visitor must press Send. TikTok embeds may be blocked by browser privacy extensions or network restrictions.
